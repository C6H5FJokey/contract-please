# 来，签合同

> 面试时说的，和纸上写的一样吗？
> 笔还没落下，一切都来得及。

《来，签合同》（contract, please）是一款单机合同交涉游戏。读合同，从想问的条款开口；碰到说不通的地方，用手里的原文回应对方，再决定是否接受改稿。

## 游戏内容

目前包含两份邀约：

- **第一章 · 泊石展务**：核对固定工资与周六轮值的结算条件。
- **第二章 · 与川数字**：厘清签约公司、入职身份、工资结算、参保与离职限制。

可以接受谈妥的改稿，按原版签署，也可以放弃合同。不同选择都会进入相应结案。

## 本地试玩

需要 **Node.js 20 或更新版本**。在项目根目录运行：

```bash
npm ci
npm start
```

然后打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。

## 进度与存档

第一章结案后解锁第二章。交涉记录、原文引用、书面改稿与章节解锁进度保存在当前浏览器中；清除浏览器数据会丢失进度。

各章可以继续审阅、回看结案或重新开始。使用 `npm start` 启动的本地试玩还包含一个独立的 [户型图测试场景](http://127.0.0.1:4173/?chapter=window-demo)。

## 开发与构建

项目使用 TypeScript、Ink 与原生 HTML/CSS，无需前端框架。

```bash
npm test       # 检查类型、剧本引用、举证与交涉规则
npm run build  # 构建用于静态托管的 dist/
```

本地试玩会构建全部候选章节；正式构建只包含已验收的发布章节。

## GitHub Pages

在仓库的 **Settings → Pages → Build and deployment** 中，将 **Source** 设为 **GitHub Actions**。推送到 `main` 后，工作流会按锁文件安装依赖、测试并构建，再发布 `dist/`。

也可以在 **Actions → Deploy GitHub Pages** 手动运行部署。
