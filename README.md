# 来，签合同

《来，签合同》（contract, please）是一款单机合同交涉游戏。读合同，从想问的条款开口。碰到说不通的地方，用手里的原文回应对方，再决定是否接受改稿。

使用 Node.js 20 或更新版本。在项目根目录运行 `npm ci` 和 `npm start`，然后打开 [本地试玩](http://127.0.0.1:4173)。运行 `npm test` 检查类型、剧本引用和关卡规则。

本地试玩从第一章「泊石展务」开始，签署或放弃合同并完成结案后，解锁待验收的第二章「与川数字」。交涉记录、引用、改稿和章节解锁进度保存在当前浏览器。各章可以继续审阅、回看结案或重新开始。

运行 `npm run build` 可生成用于托管的 `dist/`，包含已验收的正式章节。本地试玩另有一个独立的 [户型图测试场景](http://127.0.0.1:4173/?chapter=window-demo)。

## GitHub Pages

在仓库的 **Settings → Pages → Build and deployment** 中将 **Source** 设为 **GitHub Actions**。推送到 `main` 后，工作流会按锁文件安装依赖、测试并构建，再发布 `dist/`。也可以在 **Actions → Deploy GitHub Pages** 手动运行。
