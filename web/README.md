# 来，签合同 · 网页试玩版

单机合同交涉游戏，当前开放泊石展务。合同和已收到的文件可以随时阅读。只有对方的说法露出破绽时才可以圈选并提交原文，或先退回话题找材料。

在本目录运行 `npm start`，然后打开 [本机试玩](http://127.0.0.1:4173)。运行 `npm test` 检查交涉分支、举证、改稿、续关及存档。需要 Node.js 18 或更新版本。`dist` 可直接托管为静态网页。

交涉记录、提交过的原文和书面版本保存在当前浏览器。剧本入口在 [dist/chapters](dist/chapters/index.js)，写法见 [交涉框架与编剧指南](../docs/交涉框架与编剧指南.md)。
