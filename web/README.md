# 陷阱合同 · 网页试玩版

单机单人合同推理游戏。六份邀约各自包含正文、面试聊天、附件、书面修订和结局复盘。点中条款向 HR 追问，在文件里圈选具体句子，然后提交原文对照。可随时返回任意已收材料。签署前核对当前书面版本。

在本目录运行 `npm start`，然后打开 [本机试玩](http://127.0.0.1:4173)。运行 `npm test` 检查六关材料、对照判定、改稿和存档。需要 Node.js 18 或更新版本。`dist` 可直接托管为静态网页。

进度保存在当前浏览器。新版独立保存原文引用和书面版本，进入新版时需要开启新局。游戏素材与 NPC 逻辑均在本地，官方案例链接需要网络。
