# 举证与改稿

本文件与 [交涉剧本](交涉剧本.md)、[合同与材料](合同与材料.md) 合起来才是完整剧本。它明确玩家提出了什么、为什么成立、对方如何回应、最后究竟改哪些字，不依赖实装者临时编一套答案。

## 判定与记录约定

- 举证只有 P1—P6 六处。窗口外的普通追问不是一次提交，也不扣耐心。
- 每次先显示对方的待核对主张。逐项选择引用，后续内心话接在已提交的内容之后；不预先显示所有证据槽的答案。
- 引用以语义覆盖为准。能同时覆盖几项事实的一段原文应被识别，不强制玩家把同一段切成固定字符长度。完整正确的组合不因先后顺序交换而判错；结论按逻辑顺序复述。
- 对已提供的等价信息保持一致。尤其 P2 的面试确认可替代重复索要的登记或首周文件；不能为了强迫角色出场把已有证据判无效。
- 正式文件与已经保存的本人聊天都可引用。原文要带出处和发言人；不把主角内心活动当成对方的承诺。
- 举证的目标是当前争议。历史面试记录不是「旧版作废文件」，可以用来说明前后承诺不同；但已修正的结算附件不能用来指控对方现行版仍有同一个问题。
- 最后一项确认才判定。途中返回、换引用、缺资料沉默不扣耐心。错误时保留本次全部引用及具体理由，返回检查点后可沿用并逐项改。
- 成立后先说主角反驳，再进入谈改法。证据成立不等于对方接受主角提出的任何价格或条件。
- 每份新书面改稿只结算一次回血和修改次数；重新打开、重复发送、二次核对不回血。

## P1 付款是先付还是等拨款

**对方主张，许然：**「商务既然跟你签，就会按约定日期先付。数字往商务拨款是内部的事，不会影响你这边。」

**提交提示：**（她说的是没收到内部拨款也会先付。分工单对这件事怎么写？）

**成立依据：** D05.03，特别是「以收到对应核拨款为前提」「未收到时不承担先行支付责任」。这一个完整段落已经足够，不额外要求玩家证明发薪日是几号。

**主角反驳：**

我：你刚说商务会先付，不受内部拨款影响。可这张单写的是商务收到数字的款才划付，没收到不先付。同样是数字没拨款的情况，你说我能按期拿到，这里却让我跟着等。我需要把负责按期支付的公司写清楚，不能只留一个帮我协调的人。

**接续：** T1F。

**针对性错误反馈：**

| 玩家引用 | 对方回应 | 为什么不足 |
| --- | --- | --- |
| 只引用 D00.01 或 D05.01 中两个公司名 | 许然：「不同公司分工和会不会按期付，是两件事。你这段只能说明谁做哪项，没说没收到拨款时会怎样。」 | 不能由主体不同直接推定迟付或无责任 |
| 只引用 D05.02 | 许然：「这段是钱怎么转过来，转一道不等于一定要晚发。你刚才问的是没收到钱时要不要先付。」 | 正常转款路径本身不否定先行支付承诺 |
| 只引用 D00.04a 或 D01.02 | 许然：「固定数和十号发我没有否认。你要对的是内部拨款会不会成为前提。」 | 金额、日期与刚才的话可同时成立 |

其他不相关引用：许然「这段没有回答未拨款时商务会不会先付。我们先把付款前提对清楚。」随后 S_WRONG。

**无材料时沉默：** S_DEFER → T1B，索要分工单选项保持可用。

## P2 这三个月到底是不是工作

**对方主张，许然：**「这三个月主要是学习适应，还没按全职就业人员使用，所以先不走劳动合同。和登记、工作安排并不冲突。」

三项事实均需覆盖，但允许用手里已有的等价记录。

1. （合同到底把哪一段排在正式录用之前？）选择 D00.02。
2. （公司知道我是以什么身份、为了什么来的吗？）选择 D03.01，或 D01.01。
3. （“学习适应”这段，我实际上要做什么？）选择 D06.02，或 D01.05。D06.01 与正文 D00.03a 的连续对照若已完整覆盖「入组即按班次受管理并承担岗位任务」，也算覆盖这一项，不要求必须引用包含「正式」的那一句。

D03.02 的「无学校协议」可辅助理解，但不能单独替代「已毕业、就业目的」；有无学校协议并非唯一判断标准。

**主角反驳：**

我：这里把我写成三个月实践结束后再正式录用。可你们已经核过我毕业，也确认我是来找全职工作的；首周让我按班次到岗，任务交给孟乔审核，成果进正式发布。有人带我熟悉业务，不等于我没在工作。我可以接受在劳动合同里约定试用，但不接受先按正式工作的要求用三个月，手续却说还没开始。

若第三项用面试记录，则将「首周让我」替换为「孟乔在面试确认里说，入组就让我」，不伪称玩家交了尚未收到的首周文件。

**接续：** T2E。

**针对性错误反馈：**

| 缺失或误读 | 对方回应 | 回退后主角想法 |
| --- | --- | --- |
| 只有毕业登记，未证明拟实际工作 | 许然：「毕业这点我没有否认。你还得对一下这段实践实际安排什么，不能只靠毕业日期说明工作怎么使用你。」 | （毕业能证明我的状态，还要看公司准备让我做什么。） |
| 只有正式任务，未结合当前身份与原条款 | 许然：「这能说明会接项目，但你引用的几句还没把你的登记和这三个月的身份安排对在一起。」 | （我要说的是我的这份入职安排，不是所有做项目的人都一样。） |
| 引用 D00.03b 的八小时，断言有考勤就一定不是学习 | 许然：「有固定到场时间不等于已经说明了全部情况。具体做的是课程、练习还是正式任务，仍要看安排。」 | （时间表只是其中一部分，任务去向才是我还没说清的。） |

其他引用：许然「先把你的身份和这三个月实际承担的事情放在一起，不能只比较文件叫什么。」随后 S_WRONG。完整等价事实组合不归入这些错误。

## P3 七天是批次还是资格

**对方主张，许然：**「只要实际做了，那几天的报酬都有。七天只是系统合起来办一批，不是没满七天就不算钱。」

**提交提示：**（她说只是晚点办，那有没有一句写的是以后也不再给这几天建单？）

**成立依据：** D04.02。必须覆盖未满七天离场后「不转入应付」「不另行补建」的实际条件；玩家圈选整段或这些连续关键句均可。

**主角反驳：**

我：这段不是说等下一批发。它写的是没满七天离场，这几天只进适应记录，不进应付，也不再补建。按我做了五天又正常离场的情况，你刚说那五天都有报酬，单子却把它们排除了。请按实际提供劳动核算，把七天这个资格门槛删掉。

**接续：** T4F。

**错误反馈：**

| 玩家引用 | 对方回应 |
| --- | --- |
| D01.03 | 许然：「这句和我刚才说的一样，都是上过的班会结。它本身没证明结算说明在按相反条件处理。」 |
| D06.02 或 D06.04 | 许然：「这能说明第一周干什么、记录会留下，但还没说明没满七天的钱是晚发还是不发。」 |
| D00.04a 的次月十日 | 许然：「次月十号是发薪日，和首周是否有结算资格不是同一个条件。」 |

其他引用：许然「我说的是有报酬、按批次办。你这句还不能说明七天会把已经做的劳动排除掉。」随后 S_WRONG。

A2 未完成也可以成功：讨论的是假定实际提供了劳动的五天，不必先改劳动合同标题才有资格追问工资。

## P4 账号先停，申请后开

**对方主张，许然：**「账号会按规定停，但不影响你本人按流程申报。交接之后你自己登结算页提交，主管审核，就能进下一次应付表。」

若 A3 未完成，窗口明确附上前置语境「先按已经满足现行建单条件的人说」。它不会把七天问题混入本轮判定。

1. （我能用来登录结算页的账号，会在什么时候停？）选择 D09.02。它同时说明结算页与工作账号共用权限。
2. （到那时，我的结算申请已经能提交了吗？）选择 D09.03。

这两段已经构成先停后开的完整矛盾。D04.04、D09.04 能证明没有替代路径，可作为补充，不强制多交第三段已被对话确认的事实。

**主角反驳：**

我：离场那天六点，工作账号就停了，结算页用的也是这个权限。可申请要等交接后的下一个工作日才开放，还不准提前报。不是我忘了点，是按你们自己的时间走，我能登录的时候不能申报，能申报的时候已经不能登录了。请给一个不用工作账号也能办理的入口，并写清谁收、谁核、谁把已经应付的钱结出来。

**接续：** T4L。

**错误反馈：**

| 玩家引用 | 对方回应 | 说明 |
| --- | --- | --- |
| 只有 D09.02，或加了一段与开放时间无关的工资金额 | 许然：「离场停账号本身是正常操作。你要说明的是停的时候，申请是否已经能办。」 | 缺少先后关系 |
| D09.01 的个人邮箱收据与 D04.03 | 许然：「收据能发个人邮箱，不等于个人邮箱能提交结算申请。这两段并没有说是同一个入口。」 | 不能混淆接收记录与申报 |
| D04.02 七日门槛 | 许然：「我们这句先说已经符合建单条件的人。七天那项可以另外谈，它不是账号能不能登录的证据。」 | P4 不重复判 P3 |

其他引用：许然「你这几句还没把账号停用和申请开放的先后关系说清楚。」随后 S_WRONG。

如果两段正确但顺序反了，仍接受，不因步骤顺序扣血。

## P5 不补报并不是晚办理

**对方主张，许然：**「和面试说的是同一套保障。只是按批次晚一点办，报到开始这段不会少；不是前几个月就留空了。」

1. （面试承诺的是哪一种保障、从哪一天开始？）选择 D01.04。
2. （这张选择单有没有把同一段时间保留下来？）选择 D07.02。

主张中已经明确「报到开始这段不会少」，因此只提交了完整 D07.02 也已足以反驳当前话语：允许在第一步引用它后直接完成本次对照，主角复述当前话语而不冒称引用了 D01。若实现先做两步，不能把上述单段充分反驳作为错误扣血。

**主角反驳，两份材料版本：**

我：面试记录说报到起参保，这张选择单却写前三个月不申报，正式录用后只从那天开始，也不补前面三个月。这不是同一个起点晚点办手续，是直接少掉一段。四百补助不等于那段参保记录。请把从实际用工起依法办理写进正文，取消这份延后和不补报安排。

**仅反驳当前话语的版本：**

我：你刚说报到开始这段不会少，但选择单明确写前三个月不申报，也不补报。它不是晚一点办理同一段保障，而是把前面三个月留空。请删掉这个安排，把实际用工起的参保义务写清。

若 A2 已完成，可补一句：我：劳动合同已经改了，这张旧选择单也得一起清掉，不能让两份继续说不同的起点。

**接续：** T5F。

**错误反馈：**

| 玩家引用 | 对方回应 |
| --- | --- |
| 只有 D07.01 的四百元 | 许然：「有补助这一项，本身还不能证明哪段时间有没有申报。起点和是否补报得看办理那一段。」 |
| D00.04a 七千六与 D07.01 四百，断言固定工资变了 | 许然：「四百写的是固定报酬之外，七千六没有变。你现在问的是参保有没有少一段。」 |
| 已改后的劳动合同标题或两个月试用 | 许然：「劳动合同和试用期改过了，不代表这张选择单的办理起点自动变了。要核就核本单具体怎么写。」 |

其他引用：许然「这些句子还没说明哪一段参保是晚办理，哪一段根本没有安排。」随后 S_WRONG。

## P6 岗位标准和默认名单

**对方主张，郑衡：**「名单是按这份附件里的岗位标准列的，不是随便把你放进去。你现在这个岗位就在适用范围，和给你的权限安排对得上。」

1. （他拿什么条件决定谁要回避同类业务？）选择 D08.02。
2. （我这次接的岗位，实际准备让我接触什么？）选择 D10.01 或 D10.02，结合当前孟乔已确认的 D10 整份权限范围。允许选择 D10.01—03 的连续原文。
3. （不符合这项标准，附件却把我放进了什么安排？）选择 D08.03。

可缩短的充分路径：D08.02 已明确普通公开内容整理岗位不在名单，D10.01 明确本岗位只有该类内容，再加当前郑衡已确认「你在名单」的答复，已经足以反驳。若玩家针对答复提交这两段，接受并在对照记录保留郑衡那句，不强制再找 D08.03。完整三段路径用于玩家从文件论证时。

仅 D08.03—04 的两年期限与十万元金额不能证明当前岗位是否适用；数字过大不是本题唯一答案。没有 D10 时，不能仅凭「助理」职级代替岗位事实。

**主角反驳：**

我：附件先说看是否接触未公开报价、投放和经营数据，还把普通公开内容整理岗位排在名单外。孟乔给我的安排正是只做公开内容，不开这些资料权限，也不让我旁听或转发。可后面又把我这批人统一列进名单，连去同类公司做什么岗位都不区分。你说名单和实际权限对得上，这三处对不上。具体该保密的资料我会保护，但不能拿当前并没有的接触范围，先替我决定下一份工作能去哪。

若使用两段路径，将「后面又把我这批人统一列进」改为「你刚才却确认我已经在」，不假装引用了第三段。

**接续：** T6F。

**错误反馈：**

| 玩家引用 | 对方回应 |
| --- | --- |
| 只有 D00.03a 的「助理」或工资金额 | 郑衡：「岗位名称和工资多少不能说明能接触什么。我们说的是实际工作内容和资料范围。」 |
| 只有 D08.04 十万金额 | 郑衡：「你可以谈金额，但这还没说明你为什么不在适用范围。现在核的是名单依据。」 |
| 只把 D08.01 的一般信息保护与 D10 的公开权限对照，未指出名单标准和任职限制 | 郑衡：「不接触那些经营信息，和仍然要保护账号、个人信息并不冲突。你这两段说的是一般信息保护，还没对上我们在谈的任职名单。」 |

其他引用：郑衡「这几段还没把名单标准、你的当前岗位和实际限制对应起来。」随后 S_WRONG。

如果玩家只提交 D10，但明确针对「你的岗位会接触报价」这类更窄的追加主张，足以反驳的应接受。实装不得为固定答案临时让郑衡说出与当前窗口不同、更容易反驳的话，再坚持要求三段举证。

## 六份改稿

### A1 数字公司直接签约

确认节点 T1G。替换下列当前段落，其他项不擅自改动：

- **D00.01：**「甲方：与川数字有限公司。乙方担任本协议约定岗位，由甲方直接安排日常工作和管理。与川商务咨询有限公司可协助办理资料归集与款项划付，经办安排不改变甲方对乙方承担的责任。」
- **D05.01：**「与川数字有限公司作为合同甲方，负责本岗位招聘录用、岗位分配、日常考勤与管理，履行依法应承担的用工义务。与川商务咨询有限公司仅协助经办资料归集与款项划付。」
- **D05.02：**「本岗位应付报酬由与川数字有限公司按本合同约定日期支付。需要其他单位协助经办的，由与川数字有限公司负责按期完成。」

## 可用性与准确性走查

以下为编剧阶段的纸面路线。实装时仍需真人试玩，不以这份列表代替可玩性验证。

1. **常规路线：** 04 取得结算说明 → P3 → A3 → 03 拿首周安排 → 02 P2 → A2 → 01 拿分工单 → P1 → A1 → 05 P5 → A5 → 06 取得权限和附件 → P6 → A6 → 再开 04，取得离场指引 → P4 → A4 → 08 核稿 → 签。
2. **先读全套：** 08 取得所有签署附件 → 06 要权限 → P6 → A6 → 04 P4 → A4 → 再开 04 P3 → A3。后续 01/02/05 仍可独立完成；没有取得材料就自动判通关。
3. **聪明的早举证：** 从 02 开口，凭 D00 与开局 D01 覆盖 P2 → A2。无需为了拿同义材料强迫再问主管；实际岗位权限仍由 03/06 自主取得。
4. **缺资料：** 直接 01 T1E → 举证时只有合同公司名，玩家主动沉默 → 回 T1B → 要 D05 → 再到 T1E。全程未错误提交则不扣血。
5. **充分但短的证据：** P5 只选完整 D07.02 即可反驳当前答复；P6 使用标准、岗位范围和已锚定的「你在名单」也成立，不强制凑材料数。
6. **误读正常条件：** 在 03 把午休算工时、在 07 把无押金当设备赠与，被解释后仍可继续。普通误问不进入举证扣血。
7. **失败与恢复：** 在不同 P 故意提交不相关引用，确认一次只减一点，零点出现婉拒。续关后能沿用引用修改，而不是重打一章；接受一次此前未完成的改稿只回复一点。
8. **已改后继续谈：** A3 后再次从 04 主动开口，能进 P4；A4 后再次开口核对，不会再次回复耐心。
9. **不同就业主体顺序：** 分别纸面应用 A1→A2 与 A2→A1，最终均为数字甲方的一年劳动合同。D05、D03、D02 不互相打架。

12. **主动离开：** 任意阶段可拒签；不在离开后播放已入职、被扣工资或被追索的情节，不把不接受岗位边界视为举证错误。

所有改稿均为这次虚构协商的具体结果，不承诺现实中遇到同样话术必定能够要求对方接受相同报价、签约主体或文件写法。
