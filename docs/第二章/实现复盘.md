## 第二章规格评审

1. **举证。** P2 用班次和岗位职责成立时，主角不能声称已提交了成果进入正式发布的记录。P6 的两段路径需要能证明当前岗位处理的是公开资料。完整三段路径可以用权限限制作为对应证据。P2 错误反馈需要按缺失事实选择。
2. **回退。** P4 可在没收到离场指引时进入。此时沉默退回的选项必须能拿到指引，不能依赖会被静默回退跳过的发件。04 的主管路线也需要区分玩家是否已经看过七天门槛。
3. **改稿与材料。** A2 可凭开局材料成立。此前没收过的登记表和结算说明，在收到改稿时也应能比较新旧。条件不生效的改稿不能让文件悄悄变成「已收」。
4. **乱序与核稿。** A4 完成后，08 不该再用旧的账号矛盾提醒玩家。核稿应能对照当前正文、附件版本及已改内容。未收的文件需要标出来，原文留到主动索取或签后查看。
5. **发布状态。** 第二章候选实现与逐章解锁可以在本地完整测试，正式发布列表应体现章节是否已验收。验证第一章和第二章跑通只证明实现达到对应检查点。

## 修改与验证目标

1. 构建与运行读取同一份章节目录。新增沿用现有机制的章节时，编写 `chapter.ts`、`story.ink` 和需要的素材，再登记一次。与川数字用候选状态进入本地章节流程。
2. 共用签署包、普通资料领取、举证成立状态和校园卡定义。孟乔与郑衡各保留一段入群对白，六组举证继续独立写反驳和针对性错误提示。
3. 用测试重走早举证、充分证据加补充材料、没拿指引先沉默、乱序改稿和不泄露未收资料的核稿流程。签署目录从已送达的资料计算现行版本，复盘引用由每项改稿明确指定。
4. 候选版本还有完整真人试玩和节奏验收。现有屋窗测试验证了调查后开口和举证，整套租房剧本仍需根据实际调查方式来验收。
