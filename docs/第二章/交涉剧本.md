# 交涉剧本

本稿是完整对白与分支稿，不是 Ink 文件。节点名、跳转和条件供实装使用，不显示给玩家。P1—P6 的逐段举证对白及结果在 [举证与改稿](举证与改稿.md) 中；该文档是本剧本的一部分。

## 通用约定

「回合同」表示结束本轮，玩家自主选择下一条或结束审阅。任意普通对话节点均可使用「这条先谈到这里」回合同，不扣耐心；表内三个选项之外保留这个共用退出操作，不挤占话术。

「给 Dxx」表示发出完整材料并等待玩家确认看完。已经拿到则定位现行版本，不重演第一次发件。所有主角内心话均已加括号；不把制作说明读出来。

举证成立但尚未确认改稿时可以回合同。下次进入该条款直接用一句「刚才谈到的改法，我再确认一下」返回对应谈价节点，不要求重新举证。文件未修改前仍按原文展示。

每次从正文开启话题，按下表选择入口。待确认改法优先于普通入口；已经完成的争议不再让角色重复错误主张。

「待确认」只在完整改法已经提出之后记录。举证成立但尚未听到改法就退出时，返回该 P 的谈改法起点；保留已承认的矛盾，不再要求举证。04 同时有待确认改法时，选项为「确认七天计付的改法」「确认离场申报的改法」「我想再看一遍材料」。这是一轮选择的入口，不自动连续应用两项。

## 共同失败与返回

### S_DEFER 举证时先沉默

### S_WRONG 举证失败后的共用结尾

先播放对应错误的具体回应，不只出现「证据错误」。

### S_STALE 引用已被修改的旧句

只有旧句所表达的条件已经实际改掉、玩家又用它证明当前仍如此时采用。本次举证仍可逐项改引用；如果已经最终确认，按一次举证错误处理。

当前发言人：这一句我们刚才已经换掉了，旧版留着是让你核对改过什么。你要说现在还有这个条件，得看现行那一段。

### S_REFUSED 婉拒
