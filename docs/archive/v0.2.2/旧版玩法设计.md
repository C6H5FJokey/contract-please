# 《来，签合同》玩法设计

玩家扮演刚毕业的求职者，核对招聘聊天、拟签合同及随附材料。矛盾可能藏在金额的口径、待遇的适用条件或用工责任的主体里。玩家可以把资料查齐、逐条想清楚，再决定签署还是谢绝。推进取决于玩家发现和引用了什么，审阅、追问和重读不限次数。

## 一份邀约

1. 阅读招聘报价、面试聊天和合同节选，可索取正文点名的附件。
2. 选择一条合同条款，向 HR 追问一个方向，例如待遇怎么计算、什么条件下会变化、谁安排和负责。HR 或相关岗位回复，并发来与问题有关的材料。多个问题可以得到同一份材料，一次追问也可能收到多份材料。
3. 在不同文件中点选句子。每项异议包含两到三段原文，注明出处及合同版本。提交时选择只问原因、把现有条件写清楚，或协商改变条件。提交后保留原文，也可以从交涉记录重新载入某次对照。是否成立由引用的事实及适用条件决定。
4. HR 按具体引用回应。两个数字如果分别是税前和预计实发，可以同时成立。有冲突时，对方可能承认差异、只写清现行口径，或提出书面反报价。文本澄清和条件修改分别记录。新稿同步显示正文和附件的变化，旧稿可查阅对照。
5. 签署现行稿或谢绝。复盘显示原始冲突、玩家提出过哪些异议、现行文本和签下后的后果。正常合同可以直接签署。读懂条件后仍选择接受，也按真实选定的版本结算。

## 关卡如何写

为每份有问题的邀约先写出虚构雇主的利益，再写候选人看到的承诺和执行材料。每个问题都要能用两到三段具体原文指出。多主体用工关同时涉及甲方、日常管理和责任说明。主体不同本身只是线索。正常对照沿用相同的附件和提问方向，给出表面不同、口径一致的数字。

## 泊石展务的两项工资异议

面试聊天把「周一到周五正常出勤，固定税前 8,000 元」和「周六有布撤展的话，报酬另算」分成两句。追问工资构成会收到薪酬确认单，其中既有固定工资 6,800 元，也有达到周六轮值次数才发放且计入报价的津贴。玩家需要针对两项承诺分别选出附件里的对应句子。

只对照正文的「月度薪酬标准 8,000 元」和薪酬单，也可以问清八千的组成。正文没写「固定」，附件说明八千是有条件的合计。HR 要解释金额和发放门槛，玩家可以要求将现行条件写入正文。面试明确说过「固定税前 8,000 元」，那句与确认单的「固定工资 6,800 元」构成同口径的冲突。

请求写清固定工资时，HR 可以把 6,800 元写进正文，津贴条件依旧。请求修改固定工资时，HR 可以提出 7,400 元的书面反报价。周六结算由另一项异议单独调整。全改之后，周六轮值仍按项目排班。

真实取材与处理结果见 [劳动争议案例资料](../../劳动争议案例资料.md)。游戏中的公司、条款、报价、动机和谈判结果均为虚构改编。
