# 《来，签合同》 · 交涉版 v0.3

读合同，和对方谈，决定签不签。玩家从具体条款出发，在实际对话里追问金额、条件或权限。交涉没有时间和行动次数限制。难处在于听出对方什么时候换了口径，以及手里的原话能不能证明那件事。

## 一次交涉

林悦先发来合同。玩家阅读后，从任意一项正文条款选择「从这条谈」，由主角对这一项开口。每轮只谈一个话题。附件发完后等待玩家点击「看完了，继续」。谈成并收到书面改稿后回到合同，玩家可以挑下一条，也可以对已改稿的条款选择「继续谈」。修改后的文件会划掉被替换的旧句，并把现行文字放在下面。没有争议的条款也能问清细节后回去阅读，暂时谈不下去也可以结束本轮再回来。

平时从几句自然回复里选一句，通常有三个。对方可能继续聊、提供材料，或在回应里明确说出可被反驳的主张。只在第三种情况下出现原文对照。针对对方刚说的话，可以直接引用一句相反的文件原文。需要对照不同材料时，每次只确认一段，主角会用括号内的想法接到下一步。过程中也可以沉默或换个话题，补齐材料再来。

原文对照在最后一段确认后才判定。金额不同不一定有矛盾，排班和发钱条件也不等价。成立时，主角会先对对方说清两边各自怎么写、哪里冲突，再听对方答复。记录保存原文、文件名、版本和结果，下次可以沿用引用，再逐段修改或确认。

对方有五点耐心。举证失败或双方在硬要求上卡死才扣一点，并退回当前话题的检查点。单纯问材料、读文件、改口或沉默不扣。实际收到一项书面改稿后回一点，上限五点。澄清正常条款或主动搁置本轮时，耐心不变。零耐心时对方会婉拒，玩家可以离开，也可以请求继续。续关不限次数，耐心回到五点，保留已经拿到的材料、改稿和交涉记录。结案显示续关、失误、僵局和修改次数。

## 泊石展务

| 写作前确定 | 这关的答案 |
| --- | --- |
| 求职者想要什么 | 知道正常出勤到底能拿多少。即使只轮到一次周六，也能按实际出勤结算，且两件事有书面记录。 |
| 林悦想让玩家接受什么 | 运营下月缺人。她要按已批成本把人招来，并把两个周六的人手排进去。用八千的总额谈，比从六千八和发放门槛谈容易。 |
| 她知道什么，手里有什么 | 她看得到自己在面试后的聊天、薪酬组的确认单和运营的拟排班。最初只发合同正文，玩家手里另有当时的微信。 |
| 她能承诺什么 | 能调确认单、转述排班、为固定项申请一次 7,400 元的反报价。能协调改结算并发书面版本。没有权限批 8,000 元固定或免除轮值。 |

合同说「月度薪酬标准」八千，没承诺八千全是固定的。面试微信明确说周一到周五正常出勤固定八千，且周六按实际出勤另外结算。确认单用六千八固定和「去满两次才给」的一千二作合计。拟排班说明周六到场是被安排的，且场馆改期可能导致去不满两场，排班本身并不规定发多少钱。

从「劳动报酬」谈固定工资，先确认书面固定项，再找面试时同口径的报价。从「工作时间」谈周六轮值，用确认单的发放条件反驳「去一场就算一场」。林悦承认过口误后仍会争取较低的成本，能接受 7,400 元固定。周六可以谈掉发放门槛，实际排班仍由运营决定。两项可按任意顺序写入正文和确认单，也可以只谈一项、照原版签，或直接离开。

泊石展务、两次轮值和薪酬数额均为虚构。报酬打包、实际工时与书面约定的冲突借鉴了[人社部、最高法发布的劳动人事争议典型案例（第二批）案例 4](https://www.court.gov.cn/zixun/xiangqing/319151.html)。
