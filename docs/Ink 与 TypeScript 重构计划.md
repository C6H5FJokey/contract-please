# Ink 与 TypeScript 重构计划

v0.4 已实施本计划。旧版 `v0.2.2` 指向 `36c9c5c`，保留当时的完整网页和部署配置。重构以 `9fcf465` 的 v0.3.0 交涉版为基线。

## 为什么改

现版的对话、正文、引用判定和改稿混在 `boshi.js` 里。增加剧本时，编剧需要在一份 JS 里来回核对对白和规则。话题列表目前也由合同章节生成，户型图上的调查点无法独立进入交涉。

用 Ink 写对白、内心话、回复选项和分支，编剧可以在 Inky 预览这些内容。浏览器用 inkjs 执行同一份剧本。完整的举证、耐心和文件阅读流程在游戏里试玩。项目规模允许一次完成 TypeScript 迁移，集中检查剧本、文件、调查和界面之间传递的数据。 [Inky](https://github.com/inkle/inky) · [inkjs](https://github.com/y-lohse/inkjs) · [TypeScript 严格检查](https://www.typescriptlang.org/tsconfig/strict.html)

## 实现规格

| 模块 | 规格 |
| --- | --- |
| 剧本 | `content/<剧本 ID>/story.ink` 是对白、内心话、选择文字和对话分支的编辑入口。合同和材料文字、举证规则、改稿定义作为剧本数据独立存放。现有泊石对白和分支迁完后移除旧 JS 剧本。 |
| Ink 接入 | Ink 通过命名段落进入指定对话。标签使用稳定 ID，表达说话者、展示材料、进入举证、应用改稿和返回选题。接入层把标签转换为类型明确的事件。需要分支时，Ink 读取程序提供的线索、材料或改稿状态。 |
| 游戏规则 | TypeScript 持有材料版本、调查发现、举证进度、耐心、改稿、续关和结案状态。提交引用后由规则判定，再进入对应 Ink 段落。文件发出、改稿和恢复耐心只从规则层生效。 |
| 话题入口 | 剧本独立定义话题 ID。合同章节可以关联话题，户型图上的调查点也可以关联同一个或另一个话题。调查与发起对话是两个动作。程序检查入口当前是否可用，玩家确认开口后才进入 Ink。 |
| 界面 | 保留现有 HTML、CSS 和静态网页体验。UI 呈现调查点、交涉、文件和改稿。附件发完后等待玩家点「看完了，继续」。点击聊天区可跳过打字，改稿后仍可重开话题。 |
| 构建 | 将现行应用、规则、播放、预览服务器和测试统一迁到 TypeScript。用 `tsc --strict` 做类型检查，由 esbuild 生成浏览器和 Node 需要的 JS。构建时用与运行时同一锁定版本的 inkjs 编译 Ink，生成静态 `dist/`。GitHub Pages 用锁文件安装依赖并运行构建，发布这个目录。 [inkjs 编译与兼容性](https://github.com/y-lohse/inkjs#compiler) · [esbuild 的 TypeScript 支持](https://esbuild.github.io/content-types/#typescript) |

### 调查和存档

户型图使用相对图片的坐标定义调查点，缩放时点击区域跟随图片。调查点有可读名称和键盘入口。点击后可阅读观察结果，发现的线索记录到该剧本的进度，重复调查不会重复发放。作者决定某条线索是否开放新的回复或成为可引用的证据。用「窗边水渍」之类的测试场景跑通一次调查、开口、举证和改稿。正式租房文本和美术属于后续剧本。

新版提高存档版本，从新局开始。后续同版存档继续记录稳定的玩家动作，包括选择、调查、引用和附件确认。读档重放时同步恢复 Ink 的当前位置、已收材料、改稿和阅读停顿。选项使用稳定 ID，回放不依赖界面上当前第几个按钮。

## 实施顺序

1. 建立严格类型检查和静态构建。先接通一个 Ink 节点，跑通对话选择、附件暂停、保存和恢复，再迁移完整应用。
2. 提取独立话题与调查入口。用测试场景验证合同和户型图都能进入同一话题，调查也能独立完成。
3. 迁完泊石的 Ink、材料和规则，删除现役旧 JS 实现。归档里的旧版文件作为历史资料保留。更新编剧指南，记录如何用 Inky 编辑并在网页里完整试玩。
4. 做类型检查、剧本引用校验、自动测试和浏览器试玩。通过后添加许可证正文、署名和范围说明，并把适用的声明随静态产物发布。

## 验收

- 干净检出后可安装、检查、测试和构建。任一剧本的缺失话题、Ink 段落、文件、原句或改稿 ID 会在验证阶段报错。构建产物能在 GitHub Pages 的仓库子路径加载。
- 泊石仍有六个条款可由玩家开启。固定工资与周六争议可按任一顺序解决，分别支持逐段举证和单句反驳。正确举证后由主角说清矛盾。已改的工作时间仍可再次改稿，文件保留旧句删除线。附件暂停、引用沿用、耐心扣除与恢复、婉拒续关、签署和放弃的行为都按 v0.3.0 验证。
- 调查测试场景可在桌面和窄屏点击调查点，发现线索后由玩家选择与房东开口。刷新可恢复同版进度。泊石继续从合同发起话题。
- 对照代码和内容的实际文件核对许可证范围，仓库与静态产物都能找到许可及署名。
