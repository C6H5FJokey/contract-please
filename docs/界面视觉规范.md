# 界面视觉规范

《来，签合同》网页界面的视觉交接规范。适用于 `public/index.html` 与 `public/style.css`，以及任何改动这两个文件的人或代理。

玩法见 [交涉版规格](来，签合同-玩法设计.md)，发布流程见 [开发规格与交付流程](开发规格与交付流程.md)。

本文说明界面样式、DOM 钩子和验收流程。

---

## 一、设计意图

这个游戏讲的是一件事：说出口的话和写下来的字对不上。界面不该只是"好看的聊天页"，它要让人一眼看出**哪一部分是纸，哪一部分是嘴**。

所以整个界面按"值"分层，而不是按"深浅模式"分层：

| 层 | 含义 | 变量 | 色值 |
| --- | --- | --- | --- |
| 桌面 | 退后一步的底 | `--ground` | `#dfe2d9` |
| 面板 | 界面外壳 | `--panel` | `#f1f2ea` |
| 纸 | 合同与材料，全场最亮 | `--paper` | `#fcfcf7` |

**纸永远是画面上最亮的东西。** 这是硬约束。任何新增表面都必须夹在 `--ground` 和 `--paper` 之间的值域里，不允许出现比纸更亮的块，也不允许整块压暗成深色。

> 曾经用近黑底衬亮纸，被否掉了：亮暗跨度过大，在大屏上像画面破了个洞，纸的纹理和分隔线也都失去了依托。改成三段亮色后，纸读起来是"摊在桌上的文件"。**不要退回深色底。**

朱红 `--seal` 是唯一的有彩色，含义固定：**只给写下来的东西**——条款编号、版本号、引文、改稿痕迹、印章、以及主操作按钮。说话、气泡、界面外壳一律不用红。

## 二、颜色

全部颜色必须走变量，**规则里不写字面色值**。新增颜色先进 `:root`。

### 表面

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--ground` | `#dfe2d9` | 页面底、`body` |
| `--ground-deep` | `#d8dcd1` | 文件标签条、纸张凹槽 `.sheet` |
| `--panel` | `#f1f2ea` | 面板、顶栏、操作区、气泡外框 |
| `--panel-deep` | `#e9eae1` | 时间轴底、文档页脚 |
| `--paper` | `#fcfcf7` | 纸张、邀请卡、气泡、按钮底 |
| `--paper-deep` | `#eef0e6` | 版本号底色 |

### 描边

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--line` | `#c2c7b8` | 常规边框、面板外框 |
| `--line-soft` | `#d7dad0` | 面板内部分隔 |
| `--paper-edge` | `#d5d8ca` | 纸张外沿 |
| `--paper-rule` | `#e5e7dc` | 纸内条款分隔线 |

### 墨色

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--ink` | `#1e221d` | 正文、标题、纸张上的字 |
| `--ink-2` | `#4d554c` | 次要正文、引文、按钮文字 |
| `--ink-3` | `#59615a` | 说明文字、时间戳、编号。**这是最浅的可用文字色** |

### 朱红

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--seal` | `#a33127` | 主操作底、条款编号、当前版本、对照标题 |
| `--seal-deep` | `#8c2a21` | 主操作 hover |
| `--seal-mid` | `#8f4a3e` | 失败/退让类提示 |
| `--seal-wash` | `rgba(163,49,39,.07)` | 选中行、改稿行的极浅底 |

### 对比度

下表为实测值（WCAG 2.1）。**所有墨色在所有表面上均 ≥ 4.5:1**，这是当前状态，新增表面必须维持。

| | paper | panel | panel-deep | ground | ground-deep |
| --- | --- | --- | --- | --- | --- |
| `--ink` | 15.68 | 14.31 | 13.31 | 12.30 | 11.58 |
| `--ink-2` | 7.50 | 6.85 | 6.37 | 5.89 | 5.54 |
| `--ink-3` | 6.22 | 5.68 | 5.28 | 4.88 | 4.59 |
| `--seal` | 6.74 | 6.16 | 5.72 | 5.29 | 4.98 |

`--ink-3` 已接近下限。**不要再调浅**，也不要把它用在大面积文字上。

## 三、字体

四套字各有分工，不得混用。均为系统字体栈，不引入 Web 字体（离线可用、无 FOIT）。

| 变量 | 字族 | 用于 |
| --- | --- | --- |
| `--fang` | FangSong / STFangsong / Songti | **合同正文**、引文、已选原文 |
| `--song` | Songti SC / SimSun | 标题、章节名、印章字 |
| `--ui` | PingFang SC / Microsoft YaHei / 系统 | 界面外壳、按钮、说明 |
| `--kai` | KaiTi / STKaiti | 内心独白、结案回顾 |

要点：

- 合同正文用仿宋，是中文公文的实际排版习惯，也让"纸"和"界面"在字形上就能区分。
- 内心独白用楷体，是**主角的声音**，与所有其他文字在字形上不同。不要把它改成普通字体。
- 行高按语种取值：仿宋正文 `1.9`，楷体 `1.85`，界面文字 `1.5`~`1.75`。不要用统一行高。

## 四、字号与间距

正文和控件使用以下六档。

| 名称 | 值 | 用途 |
| --- | --- | --- |
| 正文 | `--text-document`（0.98rem） | 合同条款、引文 |
| 对话 | `--text-dialogue`（0.9rem） | 气泡文字 |
| 小正文 | `--text-small`（0.86rem） | 面板标题、对话框正文 |
| 控件 | `--text-control`（0.82rem） | 按钮、回复 |
| 标签 | `--text-label`（0.74rem） | 标签、卡片次要信息 |
| 微标 | `--text-caption`（0.68rem） | 署名、时间戳、编号 |

大厅和章节标题随窗口宽度缩放。文件、结案和弹窗标题共用标题档位。

```css
:root {
  --title-chapter: clamp(1.6rem, 2.6vw, 2.15rem);
  --title-lobby: clamp(3.2rem, 6.4vw, 5.6rem);
}
```

间距用 4px 栅格：`2 / 4 / 7 / 10 / 12 / 14 / 18 / 22`。段落间距取 `clamp()` 以免小屏过松。

圆角：常规控件 `2px`，纸张 `1px`，圆形头像 `50%`。气泡是唯一例外（见六.4）。**不要给卡片加大圆角。**

## 五、布局

### 桌面（> 760px）

两栏，左纸右谈。比例 `0.9fr : 1.1fr`——交谈区略宽，因为文字是主要活动。

```
┌──────────────────────────────────────────────────────┐
│ 签 来，签合同                    章节首页 重开 结束  │  masthead 62px
├──────────────────────────────────────────────────────┤
│ 泊石展务                              岗位：展务执行  │  case-title
│ ┌───────────────────────┐ ┌────────────────────────┐ │
│ │ 合同与资料      4份   │ │ 林 林悦    耐心 ▮▮▮▮▯ │ │
│ │ ┌─┬─┬─┬─┐             │ ├────────────────────────┤ │
│ │ │劳│面│校│薪│  ← 标签  │ │        签署前          │ │
│ │ ├─┴─┴─┴─┴───────────┐ │ │  ┌──────────────┐      │ │
│ │ │ ┌───────────────┐  │ │ │  │ 对方气泡     │      │ │
│ │ │ │   纸（最亮）  │  │ │ │  └──────────────┘      │ │
│ │ │ └───────────────┘  │ │ │        ┌────────┐      │ │
│ │ └────────────────────┘ │ │        │ 我的   │      │ │
│ │                        │ │        └────────┘      │ │
│ │                        │ ├────────────────────────┤ │
│ │                        │ │  01 回复…              │ │
│ │                        │ │  02 回复…   ← composer │ │
│ └───────────────────────┘ └────────────────────────┘ │
└──────────────────────────────────────────────────────┘
```

- 外层最大宽度 `1520px`，左右留白 `clamp(12px, 3vw, 40px)`。
- 页面锁高 `100dvh`，栏内各自滚动，**整页不滚**。
- 纸在 `.sheet` 凹槽内滚动，凹槽底色 `--ground-deep`，让纸浮起来。

### 平板（≤ 900px）

大厅转为单栏，标题去掉 `<br>` 强制换行。对话页仍是两栏。

### 手机（≤ 760px）

面板叠成一屏，靠 `#tab-docs` / `#tab-chat` 切换，`board[data-pane]` 决定显示哪栏。切换控件由 CSS 控制在此时才出现（`.pane-tabs { display: none }` → 显示）。

```
┌──────────────────┐
│签 来，签合同 首页│
├──────────────────┤
│ 泊石展务   岗位  │
│ ┌──────┬───────┐ │
│ │资料  │ 交涉  │ │  pane-tabs
│ ├──────┴───────┤ │
│ │              │ │
│ │   当前面板   │ │
│ │              │ │
│ └──────────────┘ │
└──────────────────┘
```

超窄（≤ 380px）再压缩顶栏并隐藏英文小字。

**750px 以下不得出现横向滚动。** 这是验收项。

## 六、组件

### 1. 按钮

三档，靠 CSS 变量 `--btn-bg / --btn-fg / --btn-line` 驱动，样式只写一次：

| 类 | 外观 | 用于 |
| --- | --- | --- |
| `.primary` | 朱红底、白字 | 主操作。一个视图内只应有一个 |
| `.quiet` | 透明底、`--line` 边、`--ink-2` 字 | 次级 / 取消 |
| `.text-action` | 无底无边、朱红下划线 | 行内操作（回看、沿用引用、取消圈选） |

最小高度 `38px`（手机 `32px`），`border-radius: 2px`。禁用态 `opacity: .35`，不改变布局。

### 2. 文件标签 `.file-tab`

形态是**档案标签**：上圆角、无下边框，选中时底色与纸同为 `--paper`，视觉上与下方的纸连成一片。

```
    ┌─────┐
    │劳动合同│ ← 选中：纸底 + 纸边，与下方纸相连
┌───┴─────┴───┐
│   （纸）    │
```

未读在标签后加 5px 朱红圆点（`.unread::after`）。**不要**改用加粗或角标。

### 3. 纸 `.paper`

`--paper` 底、1px `--paper-edge` 边、`border-radius: 1px`，使用变量 `--shadow-paper` 的双层阴影，与结案纸张共用。

```css
box-shadow: var(--shadow-paper);
```

近边一层极淡做"贴着桌面"，远层负扩散做"离开桌面"。**不要用单层均匀阴影**，那是卡片组件的默认观感，会让纸变成卡片。

### 4. 气泡

对方：`--paper` 底，`border-radius: 2px 10px 10px 10px`——尖角在左上，像从对方那里递过来。
我方：`--seal-wash` 底、朱红淡边，`10px 2px 10px 10px`——尖角在右上，镜像。

单个圆角是两方唯一的形态差异，靠它区分说话人，不靠颜色深浅。

### 5. 耐心 `#patience`

五根小竖条，宽 5px 高 14px，满格朱红，空格 `inset 0 0 0 1px var(--line)`。

```
耐心 ▮▮▮▮▯
```

**不要改回心形。** 心形属于社交产品，不属于交涉。竖条读作账面余量。

### 6. 引文与改稿

- `.quote-line`：平时隐去按钮感，只有虚线下划线；hover 浮出朱红淡边；`[aria-pressed="true"]` 时实心朱红边 + 淡底。
- `.deleted-line`：被替换的旧句，灰色 + 删除线 + 朱红淡左边线。
- `.revised-line`：现行文字，`--seal-wash` 底 + 朱红实左边线。
- `.revision-label`：`第 N 版 · 已替换`，微标字号。

改稿的可读性靠**左边界颜色**，不靠背景深浅——背景在亮模式里没有多少余量。

### 7. 对照记录 `.submission`

深一档的容器（`--panel` 底）加左引线承载原文。`.result-tag.matched` 是唯一的实心朱红标签（白字），因为"对照成立"是全游戏最关键的正反馈；未成立时只描边，不上色。

### 8. 对话框

`--paper` 底、顶部 3px 朱红边、`::backdrop` 使用 `--backdrop`。顶部红边替代了标题栏分隔线。

## 七、动效

- 只做**回应型**动效：hover 变色 `120ms`、按下、展开。不做入场动画。
- 打字机光标是唯一的循环动画，`streaming::after`，1s 阶跃闪烁。
- `prefers-reduced-motion: reduce` 时全部降为 `0.01ms`，邀请卡的位移也取消。**新动效必须在这条规则覆盖范围内。**

---

## 八、无障碍

必须保持：

- 所有交互元素 `:focus-visible` 有 2px 朱红轮廓，`offset: 2px`。纸上的描边切换为 `--seal`。
- `#announce` 是 `role="status" aria-live="polite"` 的播报区，不要移除。
- `#timeline` 是 `role="log" aria-live="off"`——故意关闭，因为逐字播放会念每一个字，改由 `#announce` 播报完整句。
- 交互状态用 `aria-pressed` 表达，CSS 直接挂在这个属性上，不另设 class。
- 文字对比度维持第二节表格所载水平。改任何墨色或表面色都要重算。

## 九、DOM 契约（改 HTML 前必读）

`src/app.ts` 与 `src/main.ts` 会在运行时插入节点、读写状态。**改 `index.html` 前先 grep 这两个文件。** 破坏这些钩子不会报编译错，只会静默失灵。

### 必须存在的 id

```
announce  avatar  case-setting  case-title  chapter-list  chapter-progress
composer  contact  contact-role  doc-count  doc-footer  docs-heading
file-tabs  finish  invitations-title  lobby  lobby-continue  lobby-continue-label
mast-actions  modal  patience  restart  sheet  tab-chat  tab-docs  timeline  workspace
```

### TS 生成、CSS 必须接住的 class

`src/app.ts` 逐字插入这些类名。**只要有样式挂在上面，改名就会静默失效。** 需与 `app.ts` 同步修改。

```
bubble  counts  deleted-line  ending  eyebrow  file-icon  file-info
file-message  file-open  floor-plan  patience-segments  inspection  log-note
message (own / incoming)  minor  modal-actions  paper  picked-quote
proof-actions  proof-header  proof-kicker  recap  reply  reply-num
reused-quotes  review-actions  revised-line  revision-label
sheet-heading  signing-files  signing-summary  source  speaker
submission  submission-heading  term  thought  topic-indicator (amended)
topic-indicators  version  quote-line  quote-chip (confirmed)
result-tag (matched)  file-tab (unread)  hotspot  setback  amendment
streaming  can-advance  can-reuse  file-review  mobile-only
quiet  primary  text-action  quote-target
```

两个例外，**是结构钩子而非样式钩子**（现无 CSS 规则，但仍有作用，不要删）：

- `document-line` —— 承载 `data-line`，供 `locateFile()` 定位滚动。
- `incoming` —— 对方气泡的语义标记，目前形态由 `.message` / `.own` 承担。

### 状态属性

| 属性 | 位置 | 含义 |
| --- | --- | --- |
| `aria-pressed` | `.file-tab` | 当前打开的文件 |
| `aria-pressed` | `.quote-line` | 已圈选 / 已使用 |
| `aria-pressed` | `.hotspot` | 当前查看的户型图点 |
| `aria-pressed` | `.pane-tabs button` | 当前面板（手机） |
| `data-pane="docs\|chat"` | `.board` | 手机显示哪栏 |
| `data-line` / `data-quote` / `data-version` | 纸内段落 | 定位与圈选 |
| `hidden` | 多处 | 由 TS 控制显隐，已全局 `!important` |

大厅主按钮通过 `#lobby-continue-label` 更新文字。箭头单独保留，HTML 缩进与换行可以正常调整。

## 十、维护约定

- 表面、文字、状态色和阴影定义在 `:root`。纸张和结案共用 `--shadow-paper`。
- 耐心数值保留在 `#patience` 的无障碍标签中。竖条由 `.patience-segments` 呈现。
- 打开弹窗时焦点落在标题。按 Tab 可依次浏览操作，按 Esc 关闭。

---

## 十一、验收

改动界面后逐项确认：

1. `npm test` 与 `npx tsc --noEmit` 通过。
2. 走完一局：开场 → 打开话题 → 圈选原文 → 发出对照 → 收到改稿（版本下拉出现、旧句划掉）→ 结案。
3. 桌面 1440px、手机 390px 各看一遍，手机**无横向滚动**。
4. 纸仍是画面最亮的层；朱红只出现在写下来的东西上。
5. 键盘走一遍：焦点可见，`#announce` 有播报。
6. `prefers-reduced-motion` 下无动画。

> `dist/` 是 gitignore 的构建产物，由 `npm start` / `npm run build` 从 `public/` 重新生成。改完 `public/` 后不需要手动同步。
